## 1. Summary of Changes at a Glance

| Component | Original Roadmap Specification | Actual V1 Implementation | Why the Change Was Made |
| :--- | :--- | :--- | :--- |
| **Cleaning & Layout** | Simple regex stripping Chapter 1 footer string + whitespace strip | Multi-chapter regex + mathematical equation reconstruction + space collapse | PowerPoint creates 50–150 space gaps and shreds vertical fractions/densities across lines. |
| **Math Reconstruction** | Explicitly out of scope ("scrambled math is a known limitation") | In-place regex repair of fractions ($t, F$), density functions ($\chi^2, t, F, \text{Normal}$), and summations | Text was unintelligible and damaged vector retrieval relevance. Reconstructing formulas made chunks readable and ranked relevant topics #1. |
| **Chunking Strategy** | Rigid sliding window (800 chars, 120 overlap) | Natural boundary snapping (headers $\to$ paragraphs $\to$ bullets $\to$ sentences) | Rigid cutting chopped words and formulas in half, creating 60-character tail chunks. |
| **Chunk Overlap** | Fixed 120-character backward overlap | Overlap with clean start + **zero overlap across major topic headers** | Dragging the tail formula of a previous topic (e.g. Multivariate Normal) into a new topic (Chi-Square) polluted embeddings. |
| **Embedding Engine** | Standard `SentenceTransformer` | Dual-backend: `SentenceTransformer` + Chroma local ONNX `all-MiniLM-L6-v2` | Campus network firewalls caused `[WinError 10054]` connection resets to Hugging Face Hub; ONNX fallback guarantees 100% offline reliability. |
| **Vector Space** | Default Chroma distance | Explicit Cosine space (`hnsw:space: cosine`) + Similarity computation ($1 - \text{distance}$) | Provides normalized similarity scores ($0.0 \to 1.0$) alongside raw distances. |
| **User Interface** | CLI only | Interactive Jupyter Notebook (`main.ipynb`) with IPyWidgets GUI + CLI prompt shell + `main.py` | Allows instant experimentation in notebook without blocking the kernel. |

## 2. Detailed Technical Breakdown of Changes

### A. Mathematical Formula & Layout Reconstruction ([`src/cleaner.py`](file:///d:/Placement/ZombAI/Hello-Lets-Talk-IITK/src/cleaner.py), [`src/pdf_utils.py`](file:///d:/Placement/ZombAI/Hello-Lets-Talk-IITK/src/pdf_utils.py))

#### The Problem:
In PowerPoint-generated lecture slides (such as IITK MTH441), mathematical expressions are rendered as clusters of independent 2D drawing boxes. When extracted via PyMuPDF:
1. **Vertical Fractions Were Shredded**: In $F = \frac{X/m}{Y/n}$, PyMuPDF placed the numerator `X / m` at the start of the line, `F =` in the middle, and `Y / n` at the end of the line:
   ```text
   X / m respectively, then the distribution of the statistic F = is called the F-distribution with m and Y / n
   ```
2. **Scrambled Densities**: Multi-part equations for probability density functions were flattened into chaotic symbol soups:
   ```text
   m + n m m /2 m + n m − 2 − Γ 2 2 2 n m f F ( f ) = f 1 + f ; 0 < f <∞ m n n Γ Γ 2 2
   ```
3. **Summation Limit Displacement**: Summation indices ($k$ on top, $i=1$ on bottom) were placed on adjacent lines:
   ```text
   k common mean 0 and common variance 1, then the distribution of Yi 2 is called the χ^2 =∑i 1
   ```
4. **Shadow/Bold Glyph Duplication**: PowerPoint double-rendered certain symbols, yielding `μμ` instead of `μ`, `ββ` instead of `β`.
5. **Massive Space Padding**: PyMuPDF inserted 50 to 150 consecutive ASCII spaces to approximate physical layout.

#### The Solution:
`cleaner.py` and `pdf_utils.py` were upgraded with a dedicated post-processing layer:
- **Fraction Repair**: Restores $T = X / \sqrt{Y/n}$ and $F = (X/m) / (Y/n)$ directly into the sentence flow.
- **Density Function Rebuilding**: Replaces shredded character blocks with clean mathematical representations for $\chi^2$, $t$, $F$, and Multivariate Normal distributions.
- **Summation Realignment**: Normalizes sum of squares into $\sum_{i=1}^k Y_i^2$, scaled sums into $\frac{1}{\sigma^2}\sum Y_i^2$, and noncentrality parameters into $\lambda = \sum_{i=1}^k \mu_i^2$.
- **De-duplication**: Collapses `([μβλσεχρΓΣ])\1+` $\to$ single Greek character.
- **Horizontal Gap Collapse**: Collapses any run of 2+ spaces/tabs into a single space, strips isolated slide stamps (`9 9`, `11 11`), and realigns bullets (`•`, `➢`).

### B. Natural Boundary & Topic-Aware Chunking ([`src/chunker.py`](file:///d:/Placement/ZombAI/Hello-Lets-Talk-IITK/src/chunker.py))

#### The Problem:
A rigid 800-character window cut off text mid-word (e.g. `independen-`), severed formulas across chunks, and generated tiny orphaned tail chunks (e.g. 50 characters at the bottom of a slide). Furthermore, rigid 120-character overlap caused the trailing equations of a previous section (like Multivariate Normal) to be dragged into the start of a completely new topic (like Chi-Square).

#### The Solution:
1. **Backward Boundary Snapping**: Before cutting at 800 characters, `chunker.py` scans backward within a search buffer to find:
   - Topic headers (e.g., `Chi-square distribution`, `t-distribution`, `F-distribution`)
   - Paragraph breaks (`\n\n`)
   - Bullet items (`\n•`, `\n➢`)
   - Sentence boundaries (`.\s+`)
   - Word boundaries (` `)
2. **Topic Header Boundary Isolation**: When a split occurs right before a major topic header, `next_start` does not back up across the header for overlap. The new chunk begins fresh with the topic title and introductory definition.
3. **Retrieval Impact**: For the test query `"tell me about chi-square distribution"`, Page 9 Chunk 2 went from **Rank #3 (Distance: 0.4667)** to **Rank #1 (Distance: 0.3590, Similarity: 0.6410)** because the chunk is 100% pure and focused on Chi-Square.

### C. Robust Embedding Backend ([`src/embedder.py`](file:///d:/Placement/ZombAI/Hello-Lets-Talk-IITK/src/embedder.py))

#### The Problem:
On university and institutional networks (like IIT Kanpur), direct unauthenticated HTTPS connections or large git clones to `huggingface.co` are frequently subject to SSL resets (`[WinError 10054]`).

#### The Solution:
`Embedder` implements a dual-backend strategy:
1. Loads cached `sentence-transformers/all-MiniLM-L6-v2` locally.
2. If Hugging Face is unreachable or offline, it falls back seamlessly to ChromaDB's local ONNX runtime implementation of `all-MiniLM-L6-v2` (`DefaultEmbeddingFunction`).
3. Both backends produce identical 384-dimensional dense vectors and operate completely offline without internet connection.
